墨池 · 原理

一張圖，是怎麼抽出來的

墨池是一副 — 張的牌。每張牌是一個 Danbooru 標籤，配中文名和一張卡面。你放幾張，引擎照規則把其餘補完，排成一段提示詞，送進 ComfyUI 畫出來。

不懂程式也看得懂：往下捲，每一章都可以點、可以試。

從頭看

01

從啟動開始

雙擊 start.bat：它只做一件事，開一個小伺服器（server.py），再打開瀏覽器。第一次要準備的東西，都由伺服器在背景做，網頁左下角的面板一項項顯示。

  1. 卡面插畫從 GitHub Release 下載公開的全年齡卡面（先抓幾十 MB 的縮圖，原圖背景接著抓）。不用 ComfyUI。
  2. 預覽縮圖（Pillow）沒裝就裝：LoRA、底模的預覽圖縮成小檔，面板開得快。
  3. 等 ComfyUI 開起來還沒開的話，下面這些先等著；一開就接著做，不用再跑一次 bat。
  4. LoRA Manager問過你才裝進 ComfyUI：LoRA 清單、預覽圖、觸發詞都從它來。
  5. Hires 放大模型約 18 MB，放進 ComfyUI 的 upscale_models。
  6. 姿勢參考OpenPose 節點＋模型（約 2.5 GB）：照一張圖的姿勢擺。
  7. 修臉（FaceDetailer）只重畫臉的那顆按鈕要的節點、偵測模型、SAM（約 425 MB）。
  8. 圖片解析（WD14 Tagger）解析池要的節點和 wd-vit-tagger-v3 模型（約 380 MB）。
  9. 烘焙卡面缺的、提示詞改過的全年齡卡面，用你的 ComfyUI 直接畫。
  10. 敏感、色情、角色卡面不公開下載的那些：問一聲，要的話在你的電腦上烤。
自己做 先問你 等 ComfyUI

怎麼知道缺什麼？ 伺服器問 ComfyUI「你有哪些節點、哪些模型」（object_info），再看資料夾裡的檔案；都有的人完全看不到這個面板。

卡面怎麼烘？ 每張牌一段固定的提示詞：一定寫 adult、mature，負面詞擋 loli、child；同一個種子，誰烤都一樣。烤好存一張原圖、兩種縮圖，清單記著每張是用哪段提示詞烤的，提示詞一改就知道要重烤。

02

架構一張圖

抽牌在你的瀏覽器裡算，畫圖交給 ComfyUI，中間的伺服器負責轉送、存檔、記帳。點任何一塊看它在做什麼；下面的按鈕演一次「按下抽並生圖」資料怎麼走。

03

牌與詞庫

牌分七種花色，每種花色再分細分類。點一種花色看裡面有什麼。所有數字都是現在這份詞庫即時算的。

—張牌
—個細分類
—個互斥格
—張會附帶別張

詞庫是怎麼做出來的

  1. 原料web/lexicon_parts/ 裡的原料、角色表、建議清單：一行一個字，寫它屬於哪裡、跟誰互斥、附帶什麼、哪些時代、哪些尺度。
  2. 合併merge_lexicon.py 把原料併成一份，對 Danbooru 改名表，擋掉禁用字。
  3. 中文名add_zh.py 補上每張的中文名。
  4. 卡面工作表card_art.mjs 算出每張牌的卡面提示詞；bake_card_art.py 照它烤。
  5. 互斥圖、加入日誰跟誰不能同框的總表；每張牌第一次進詞庫的時間（卡冊排序用）。

新字要先對 Danbooru（有沒有這個字、多少張圖），再用固定的五個種子試畫；畫不出來、畫錯、畫成小孩的不收。

    互斥與附帶

    一張圖只會有一種髮色、一種瞳色、一種髮長：同一格的牌「互斥」，新放的會把舊的換下來。有些牌放進來會「附帶」別張：夏日洋裝一定是洋裝。這兩件事都可以在墨池的規則裡關掉。

    互斥：點一個髮色放進池子

    附帶：放一張會帶別張的牌

    06

    分級、尺度、時代

    分級是上限：全年齡、敏感、色情，往上一級才多開一批牌。尺度是這一張要多露：活動、誘惑、走光、性愛。時代決定場景和衣服：江戶抽木屐、和服，現代抽球鞋、地鐵站。

    活動穿著整齊，做事情：讀書、跑步、做菜。
    誘惑撩人但不露點：泳裝、睡衣、姿勢。
    走光衣服掀開、意外露出。只在敏感以上。
    性愛只在色情分級。要兩個人以上的動作，人數不夠就不抽。

    07

    怎麼擋未成年

    不是只靠一道牆：從詞庫到送出前，一共五層。任何一層擋到，那個字就到不了 ComfyUI。

    loli未成年角色child
    1. 不做成牌loli、shota、baby 這類未成年相關的字：詞庫認得、但永遠不做成牌，抽不到、釘不住；從別處貼上的提示詞也不收（貼上會說「不收」）。
    2. 禁用角色— 個角色查過年齡：未滿 18、學生、外觀像兒童、真人，一律不能抽。卡冊打開「含禁用」只列名字，不能用。
    3. 新字要試畫每個新字用五個種子試畫，畫成小孩的不收。
    4. 卡面提示詞每張有人物的卡面都寫 adult、mature female／male，負面詞擋 loli、child、teenage；兩人以上的不畫成全家福。
    5. 送出前再查一次伺服器送 ComfyUI 之前把整段提示詞再對一次禁用表，有就整張不送。

    五個房間

    頂欄的五個分頁，各管一件事。點一個看它能做什麼。

    09

    生圖之後

    按下「抽並生圖」之後，一張圖會走過這幾站。

    1. 排隊伺服器把提示詞套進工作流程（底模、LoRA、尺寸、種子），交給 ComfyUI。同時印好幾張會排隊。
    2. 邊畫邊看ComfyUI 每一步的預覽即時傳回網頁；卡住、斷線會自己接回來，手機換頁也看得到進度。
    3. 印好了成品掛上牆。每張都記著「你放的牌」和「引擎補的牌」，可以單張撤下、收藏、照這張再印。
    4. 再加工Hires 放大、修臉（只重畫臉）、換底模重印，都從成品下面的按鈕。
    5. 記帳每張圖寫進出圖日誌；用到的牌各加一次，卡冊就知道誰常出好圖。
    6. 送出去設定了 Discord，就照分級、角色、標籤分頻道送過去。

    10

    品質

    每改一次，整套測試跑一遍再推上去。

    45段測試，同時跑約 16 分鐘：抽牌規則、互斥、分級、時代、伺服器、網頁畫面、英文版。
    2400張固定種子的抽牌指紋：引擎的抽法一變就知道。
    2個 repo：墨池另外開源成 danbooru_tag_mochi，每次同步、在 Windows、Mac、Linux 上自動測。

    看懂了，就去試一次。
