01

五個房間

每個房間做一件事，牌可以在房間之間帶來帶去。

墨池 放幾張牌，按一下「抽並生圖」：引擎補齊其餘的牌，送 ComfyUI 畫。成品掛在牆上，可以收藏、放大、修臉、照這張再印。 疊印台 一張牌一層墨，照花色疊進卡池。先看四張試印的提示詞，挑一張再付印。 卡冊 每張牌用過幾次、出過哪些好圖；收集進度和成就，喜歡的牌收進偏好卡牌。 作品冊 收藏的、印過的每一張：大圖、用了哪些牌、哪個模型，一鍵帶回墨池再印。 解析池 丟一張圖進來，認出畫面裡的標籤，詞庫有的變成牌，帶去合成池或疊印台。

02

不是亂抽

引擎每抽一個字，都先問過規則。

  • 懂畫面一張圖只有一種髮色；雙馬尾帶出髮飾；夜景不配陽光；室內不下雨。互斥、附帶、時代、白天黑夜都有規則。
  • 分級分得清全年齡、敏感、色情三段，再配尺度。跟未成年有關的字一律擋掉，不會抽到、也送不出去。
  • 你的電腦、你的模型連你自己的 ComfyUI：底模、LoRA、放大、修臉、姿勢參考都在面板裡挑。資料只存在你的電腦上。
  • 手機也能印走 Tailscale 連回家裡那台，躺在床上挑牌，電腦在書桌上畫。

03

一起來玩

  • 分享你印的圖、看別人怎麼配牌
  • 問用法、回報問題，有人會回
  • 許願想要的牌、規則、功能
  • 新版、新卡面第一時間公告

在墨池裡也找得到：頂欄的「社群」。

GitHub 開源

程式碼用 GPLv3 授權，誰都可以看、可以改。更新紀錄、卡面包也都在這裡。

04

  1. 裝好 ComfyUI墨池不碰模型本身，只把工作流程交給 ComfyUI 畫。底模推薦 WAI-Illustrious。
  2. 下載墨池在 GitHub 按 Code → Download ZIP，或用 git：
  3. 雙擊 start.bat它開一個小伺服器、打開瀏覽器。第一次來會問你要不要加入 Discord，再帶你走一遍導覽。
